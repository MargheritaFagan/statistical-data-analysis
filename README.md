# Statistical Data Analysis
This repository contains selected academic projects developed during my Master's degree in Statistical Sciences at the University of Bologna.
The projects illustrate my experience in statistical programming, data management, predictive modelling and data visualisation using R, Stata and SAS.

## R
Applications of statistical learning methods, including model selection, regularisation, cross-validation, classification and tree-based methods.

## Stata
Data preparation, variable construction and statistical analysis, including event-history methods.

## SAS
Data preparation, merging and aggregation of datasets, creation of derived variables and statistical reporting.

The code included in this repository was developed as part of academic coursework and team projects.
